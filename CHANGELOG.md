# Changelog

All notable changes to **Clover Motion Studio** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-05

### Added
- **Clover Motion Brand Identity**: Custom 4-leaf Clover emblem, `clover.motion` wordmark, browser favicon (`c` + clover leaf), and signature Clover Green (`#159947` / `#16a34a` / `#22c55e`) UI accent system.
- **Complete 27-Template Motion Library + Sound Check**:
  - *Start here*: `Hangul Modules`, `Pattern Playground`, `Shutter Play`, `Split Signal`, `Paper Stack`, `Prism Radio`
  - *Kinetic type*: `Cutout Credits`, `Variable Chants`, `Circular Loop`, `Offset Echo`, `Whisper Loud`, `Kinetic Chant`, `Split Counter`, `Strobe Cut`, `Echo Stack`
  - *Graphic systems*: `Press Register`, `Field Shift`, `Signal Cross`, `SolarTicker`, `Grid Index`
  - *Expert collection (16s / 4 scenes)*: `Obsidian Orbit`, `Silk Frequency`, `Hyper Assembly`
  - *Studio collection*: `Bureau Grid`, `Contour Study`, `Chromatic Cut`, `Blue Pleat`, `Ribbon Pulse`
  - *Starter*: `Sound check` (60s 12-column audio-reactive visualizer matrix)
- **12 Swiss Poster Layout Blueprints**: `01 Stacked` through `12 Wide margin` with tilted architectural preview cards.
- **Dual Workflow Modes**:
  - **Quick Editor**: Guided customization (`Content`, `Style`, `Motion`, `Sound`) with multi-format text fit verification.
  - **Advanced Studio**: Collapsible icon rail, linked `Quick Edit` fields, `Graphics` template gallery, `Scenes` transition manager, and `Stack` layer manager.
- **Multi-Property Keyframe Timeline & Value Graph**:
  - Proportional `Scenes` bar, collapsible timeline bar, expandable per-layer property tracks (`Position X`, `Position Y`, `Scale`, `Rotation`, `Opacity`), `Value graph` curve editor, and `Beats & markers` toolbar.
- **24-Track Procedural Web Audio Synthesizer & Live FFT Engine**:
  - Categorized audio track selector (`Your audio`, `Recommended · by use`, `More · Grooves`, `More · Atmospheres`, `More · Electronic`, `More · Beats & bass`), custom `.mp3/.wav` upload, live Microphone input, and 5 real-time signal meters (`Amplitude`, `Bass`, `Mids`, `Treble`, `Transients`).
- **Complete Studio Modal Suite**:
  - `TemplateLibraryModal`, `BrandKitsModal`, `MotionTemplatesModal`, `FormatReviewModal`, `ExportModal` (MP4/WebM/PNG/JSON), `MyProjectsModal`, `FullscreenPreviewModal`, and `HelpShortcutsModal`.
